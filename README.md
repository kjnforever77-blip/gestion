# EAenJC — Gestion scolaire

Application de gestion scolaire des écoles Être et Avoir en Jésus-Christ (Bobo-Dioulasso) :
registre des élèves, inscriptions, frais et reçus, notes, bulletins, listes.

Ouvrir : https://kjnforever77-blip.github.io/gestion/ puis « Installer l'application » dans Chrome.

Les données des élèves ne sont **pas** dans ce dépôt : elles restent sur chaque ordinateur
et dans le fichier de données partagé (OneDrive).
